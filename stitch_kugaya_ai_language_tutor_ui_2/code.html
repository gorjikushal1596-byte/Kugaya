Exam-Ready Answer

10 / 10 Mark Template

“A Pointer is a variable holding a memory address with its own separate storage and reassignment capability, whereas a Reference is an immutable alias sharing the identical memory address without additional storage overhead.”

Quick Code Proof
int a = 10;
int* ptr = &a; // Own address, holds &a
int& ref = a; // Alias, shares &a directly
