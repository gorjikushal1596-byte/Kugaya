## Brand & Style

This design system establishes a high-performance, cognitive aesthetic tailored for intelligent, voice-first regional language learning across India. The visual atmosphere fuses the precision of cutting-edge AI computation with the cultural warmth of Indic oral traditions. 

The aesthetic is anchored in **Futuristic Neon Glassmorphism**:
- Ultra-dark canvases representing deep cognitive space, pierced by high-luminance coherent light beams (electric cyan, neon violet, and atmospheric blue).
- Translucent, frosted glass surfaces that layer complex educational hierarchies without visual heaviness.
- High-contrast typography optimized for rapid bilingual reading, code-switching (e.g., Hinglish, Tenglish, Kanglish), and Indic orthography.
- Focused, intentional luminescence where glow signifies active state, real-time AI comprehension, and voice energy rather than passive decoration.

## Colors

The palette operates strictly in dark mode, optimizing display emissions and providing extreme dynamic contrast for neon-luminescent signals.

### Core Swatches
- **Canvas Base (`#080B14`)**: Deep Midnight Black. The infinite depth foundation. Never use pure black (`#000000`).
- **Surface Elevation (`#101729`)**: Dark Navy container foundation.
- **Glass Overlay (`rgba(16, 23, 41, 0.75)`)**: Frosted surface light for cards, modals, and flyouts with backdrop blur.
- **Primary Accent (`#00E5FF`)**: Electric Cyan. Signals high-priority interactions, real-time voice capture, and AI active processing.
- **Secondary Accent (`#985EFF`)**: Neon Violet. Used for linguistic nuance, grammatical breakdowns, and higher-order intelligence milestones.
- **Supporting Accent (`#477BFF`)**: Soft Vibrant Blue. Manages structural UI elements, contextual links, and secondary interactive points.
- **Semantic Success (`#10E79D`)**: Soft Neon Green. Dedicated to correct pronunciations, verified quiz answers, and retention progress.

### Text & Contrast Hierarchy
- **Text Primary (`#F4F7FF`)**: Near-white with subtle cool balance. Reserved for primary instructional text and Indic script bodies.
- **Text Secondary (`#929BB0`)**: Cool Grey for phonetic guides, romanized translations, and metadata.
- **Text Muted (`#5F6A85`)**: Slate Grey for disabled states, structural borders, and non-interactive timestamps.

### Neon Strokes
Borders leverage linear directional gradients ranging from `rgba(0, 229, 255, 0.18)` at the upper light-incidence point to `rgba(152, 94, 255, 0.12)` along the base, preventing flat, boxed containment.

## Typography

Typography prioritizes multilingual rendering without glyph clipping or vertical rhythm shifts. **Plus Jakarta Sans** provides wide optical apertures, robust horizontal terminals, and geometric proportions that maintain extreme clarity alongside complex Indic diacritics and matras (Telugu, Devanagari, Tamil, Kannada, Malayalam).

### Script & Code-Switching Principles
- **Line Heights for Mixed Scripts**: Indic scripts require 10–15% more vertical clearance than Latin alphabets to avoid clipping vowel modifiers (kombu, matras, ottulu). All line heights accommodate mixed-script inline sentences (e.g., Latin + Telugu script) seamlessly.
- **Transliteration Pairing**: When presenting romanized hybrid texts (Hinglish/Tenglish), set the vernacular source in `body-md` (`#F4F7FF`) and romanized phonetics in `body-sm` (`#929BB0`) directly beneath or inline, maintaining clean baseline alignment.
- **Hierarchy Separation**: Reserve uppercase styling strictly for `label-sm` technical tags. Never set full Indian language transliterations in all caps.

## Layout & Spacing

The layout is built on a responsive 12-column grid system for large displays that scales to a fluid 4-column structure for mobile viewports, prioritizing ergonomic thumb zones for high-frequency voice interaction.

### Breakpoints & Canvas Bounds
- **Mobile (< 768px)**: 4 columns, `margin` = `1rem`, `gutter` = `1.25rem`. Cards and interactive conversational elements span full width.
- **Tablet (768px – 1024px)**: 8 columns, `margin-tablet` = `2rem`, `gutter` = `1.5rem`.
- **Desktop (> 1024px)**: 12 columns, max content container width `1280px`, `margin-desktop` = `3rem`, `gutter-desktop` = `2rem`.

### Spatial Rhythm
- Apply strict multiples of 4px/8px using the defined spatial scale tokens.
- Internal component padding relies on `space-md` for compact utility items and `space-lg` to `space-xl` for educational breakout cards to provide breathability around dense multilingual explanations.

## Elevation & Depth

Depth in this system avoids heavy opaque drop shadows. Instead, it relies on **Luminescent Glass Layering**, combining selective back-surface light diffusion, backdrop blur, and calibrated refractive borders.

### The 4 Depth Tiers

1. **Surface 0 (Canvas Base)**: Pure `#080B14`. Non-elevated background host.
2. **Surface 1 (Base Glass Containers)**: Background `#101729` at 85% opacity with `16px` backdrop-filter blur. Rimmed by a single 1px stroke of `rgba(255, 255, 255, 0.05)`.
3. **Surface 2 (Elevated Educational Cards)**: Background `rgba(16, 23, 41, 0.75)` with `24px` backdrop-filter blur. Rimmed by a gradient outline: `linear-gradient(135deg, rgba(0, 229, 255, 0.20), rgba(152, 94, 255, 0.10))`. Ambient shadow: `0 12px 32px -8px rgba(0, 0, 0, 0.6)`.
4. **Surface 3 (Active AI & Focused Modals)**: Background `rgba(21, 31, 56, 0.85)` with `32px` backdrop-filter blur. Outlined by `rgba(0, 229, 255, 0.5)`. Ambient bloom: `0 0 24px 0 rgba(0, 225, 255, 0.20), 0 20px 40px -10px rgba(0, 0, 0, 0.8)`.

### Neon Radiance Rules
- Glow effects must be confined to interactive focus, successful retention states, or active audio processing. Never use glow as static card backgrounds.
- Glow radii must remain soft (spread radii between `12px` and `32px`, opacity strictly beneath `0.35`) to prevent optical vibration against deep backgrounds.

## Shapes

The geometric signature uses rounded contours that soften the technical precision of the dark neon environment.

- **Primary Educational Cards**: Constructed with an exact curvature between `18px` and `22px` (`1.125rem` to `1.375rem`), establishing a tactile, approachable container for technical concepts.
- **Interactive Controls (Inputs, Primary Buttons)**: Normalized to `rounded-lg` (`1rem`).
- **Interactive Chips & Voice Pills**: Full rounded pill silhouettes (`rounded-full` / `9999px`) to visually reference audio capsules and mobile touch targets.
- **Inner Nested Elements**: When a nested child card sits inside an educational frame, reduce its corner radius to match the visual concentricity (`outer_radius - padding_offset`).

## Components

### Buttons & Interactive Voice Controls
- **Primary Voice Action Button**: Pill-shaped (`rounded-full`), minimum 56px height. Filled with high-luminance gradient from `#00E5FF` to `#477BFF`. Text is high-contrast `#080B14` bold. When listening, pulses a circular outer halo of `rgba(0, 229, 255, 0.35)` scaled synchronously via CSS keyframes.
- **Secondary Buttons**: Transparent dark navy base (`rgba(16, 23, 41, 0.6)`), 1px border `rgba(0, 229, 255, 0.3)`, text in `#F4F7FF`. On hover, the border transitions to solid `#00E5FF` with a micro-glow of `0 0 12px rgba(0, 229, 255, 0.2)`.

### Multilingual Selector Chips
- Elliptical pills housing script tags alongside Latin descriptions (e.g., `తెలుగు Tenglish`, `हिन्दी Hinglish`).
- **Default State**: Surface navy (`#101729`), 1px border in `rgba(95, 106, 133, 0.3)`, text `#929BB0`.
- **Selected State**: Subtle radial gradient background of `rgba(0, 229, 255, 0.12)`, border in `#00E5FF`, text in `#F4F7FF`, with a leading 6px neon micro-dot indicator.

### Educational AI Cards
- **Concept Breakdown**: Surface 2 glass elevation, 20px radius. Header flanked by a violet technical badge (`#985EFF`). Typography separates core regional vocabulary from root linguistic derivations.
- **Real-World Analogy Card**: Left accent border in `#477BFF` (3px thickness). Displays informal conversational metaphors in Tenglish/Hinglish using high-readability italicized accents.
- **Exam-Ready Notes**: High-contrast, structured card containing bulleted memory hooks. Code/syntax blocks embedded inside use an interior dark capsule with 1px border `rgba(152, 94, 255, 0.2)`.
- **Interactive Quick-Check Quiz**:
  - Options act as selectable glass rows with rounded-lg (`1rem`) geometry.
  - Hover: Border glows soft cyan (`#00E5FF`).
  - Correct Feedback: Border transitions to `#10E79D` with a soft green inner ambient bloom (`rgba(16, 231, 157, 0.15)`).
  - Incorrect Feedback: Border flashes muted crimson with subtle mechanical shake animation.

### Real-Time Audio Waveforms
- Displayed as vertical oscillating rounded bars (width: 3px, gap: 3px, border-radius: 9999px).
- Low amplitude uses `#477BFF`; peak amplitude blooms into `#00E5FF`. Ambient baseline sits at 20% opacity when idle.

### Technical Terminology Pills
- Inline micro-capsules (`rounded-full`, 4px vertical padding, 10px horizontal padding).
- Used within continuous sentences to highlight keywords. Background `rgba(152, 94, 255, 0.15)`, text `#985EFF`, stroke `rgba(152, 94, 255, 0.3)`. Tapping triggers an instantaneous pronunciation popover.
